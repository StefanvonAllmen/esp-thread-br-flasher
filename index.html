ESP Thread Border Router

ESP32-S3 + ESP32-H2 board. Use Chrome or Edge, connect the board via its ESP32-S3 USB port.

Normal firmware

For boards that are already set up (Wi-Fi and Thread saved). Updates the firmware and keeps the settings. Auto-start, Wi-Fi retries forever, up to 64 child devices.

Setup firmware

For a new board: manual start, so Wi-Fi and the Thread dataset can be entered in the serial console. Afterwards install the normal firmware.

Do not tick "Erase device" for a board that is already set up: it deletes its saved Wi-Fi and Thread settings. On a new board erasing is fine.

New board, step by step

  1. Install the setup firmware.
  2. Open a serial console (115200 baud) and enter:
    ot wifi connect -s <wifi name> -p <password>
    ot dataset set active <dataset from Home Assistant>
    ot ifconfig up
    ot thread start
    after ~30 s ot state must say router or child.
  3. Install the normal firmware.
